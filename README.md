# Content Engine voice model

An unchanged copy of [Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)
(OpenAI Whisper small, converted for CTranslate2), MIT licensed. The Content Engine downloads it from
here so it works with Claude's default network settings. `model.bin` is split into parts under
GitHub's file limit; `SHA256SUMS` checks the parts and the rebuilt file.
